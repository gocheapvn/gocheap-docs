# Hướng dẫn gửi yêu cầu hỗ trợ

<span id="lien-he-cskh"></span>

- **Hotline:** [024 7300 0636](tel:+842473000636)
- **Email:** [hotro@gocheap.vn](mailto:hotro@gocheap.vn)
- **Zalo:** [GO’Cheap trên Zalo](https://zalo.me/0934343141)

Khi cần hỗ trợ, khách hàng và đối tác nên chuẩn bị:

- Họ tên.
- Số điện thoại đăng ký.
- Mã chuyến hoặc mã giao dịch.
- Thời gian xảy ra sự cố.
- Mô tả vấn đề.
- Hình ảnh hoặc tài liệu liên quan nếu có.

## Quy trình tiếp nhận

1. Ghi nhận yêu cầu.
2. Phân loại vấn đề.
3. Chuyển bộ phận phụ trách.
4. Kiểm tra thông tin.
5. Phản hồi hướng xử lý.
6. Xác nhận kết quả.
